# Dot and interval plots

- Enable `"chart-intervals": true` in site or page `features`. It loads [SVG charts](charts.md) as a dependency. Use `data-df-chart="interval"` in markup.
- `x` is a category and `y` is a linear numeric estimate in both orientations. `orientation: "vertical"` (default) places categories along the bottom. `"horizontal"` lists them down the left, wraps long labels, and sizes the plot by row count unless `height` is set. Also accepts `data-df-orientation`.
- `sort: "value"` (default) ranks highest first by the first series. Set `sortSeries` to another series key. Ties keep input order. Categories without a value in the ranking series go last. `"label"` sorts alphabetically and `"none"` keeps input order (`categories` first, then first appearance). Hiding a series keeps the category order.
- `mark: "dot"` (default) scales to the estimates and supplied bounds. `"lollipop"` draws stems from zero and includes zero in the automatic scale. A fixed value domain that excludes zero puts stems at the nearest plot edge.
- Use one estimate per category per series. Multiple series sit side by side within each category. Set `toggles: true` or `data-df-toggles` for legend filtering. Remaining series recenter. `rescale: true` fits the value axis to the visible data.
- Points accept pairs or objects such as `{x: "North", y: 28, key: "north-before", interval: {lower: 24, upper: 33, label: "Example bounds", count: 12}}`. Bounds are optional finite numbers with `lower ≤ upper`. The estimate may fall outside the supplied bounds. `label` and nonnegative integer `count` are optional. Use the standard column-series mapping with `interval` fields for named sources.
- `referenceLines: [{axis: "y", value: 25, label: "Target"}]` marks a value in either orientation. Use `axis: "x"` with a category label to mark a category.
- Use `selectionGroup` and stable point `key` values for linked selection. Hover or use arrow keys to inspect marks, click or press Enter to select, and open **Table** for ranked estimates and interval text from visible series. An authored table supplies a script-free fallback. Default chart motion applies to keyed updates and legend filtering.
