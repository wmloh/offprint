# Numbering and cross-references

Load `css/refs.css` and `js/refs.js`. Numbering runs on page content at initialization. Figure, table, and equation counters are independent and start at 1 per document.

```html
<figure id="trace">
  <img src="trace.png" alt="Residual trace">
  <figcaption>Residual by hour.</figcaption>
</figure>
<div class="df-math" data-df-display id="residual">r = y - \hat y</div>
<p>See <a href="#trace"></a> and <a href="#residual"></a>.</p>
```

- A non-nested figure or a table outside a figure qualifies with its own caption, ID, or `data-df-number`. A figure containing a table counts as a table unless it also contains a chart host, SVG, image, canvas, video, or math outside the table. Qualifying items receive a caption if needed.
- Display equations outside figures qualify with an ID, `data-df-number`, or `refs: {equations: 'all'}`. `data-df-no-number` on an item opts it out. Numbered elements gain `data-df-label`. Equation numbers live in `data-df-number` so rerenders preserve them. Load the [math assets](math.md) to render TeX.
- Use an explicit target ID and an `href="#id"` for same-page links. Empty links get the target's numbered label, heading text, `title`, or ID. Missing targets warn and empty links show `??`. On activation the target flashes. Local refs use `--df-xref`.
- `tooltip.js` provides same-page preview cards for linked items, with up to three following blocks for headings. Links to pages in the manifest get cross-page previews from `search.js` and the index, or a URL display when unavailable. `data-df-no-preview` on a link or ancestor skips cross-reference enhancement, including automatic label text and flashing.
- Load `refs.js` before `nav.js` for the generated References heading from [citations](citations.md). Link resolution runs after synchronous initializers so it can use IDs generated by navigation.
