Data file converter

DocForm pages opened from files cannot read other files, so data reaches them as scripts. Choose CSV, JSON, or YAML files and this page wraps each one as a script that registers its text under a name. Everything runs in this page; nothing is uploaded.

Save each result beside your page, include it with a <script src> tag before core.js, and show it with <div data-df-data="name"></div>. Convert the file again after editing it.
