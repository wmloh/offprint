What DocForm is

A DocForm site is a set of web pages that readers open in a browser, the app they use to view web pages. The pages and the files that give them their appearance and controls can all live on the reader’s computer. That’s how the site works offline.

What you can make

  • Study notes that explain unfamiliar words as readers meet them.
  • A lesson or walkthrough that lets a reader go through one step at a time.
  • A report with charts and tables readers can explore to answer their own questions.
  • A reference site where readers can browse or search for the page they need.

How these docs are organized

The sidebar is the panel that lists the pages. Start here helps you open a site and use its reading tools. Design with hierarchy shows how to guide a reader’s attention through a page.

The feature guides are grouped by what you want to do, from writing clearly to showing data. The Recipes put several features together for one goal. Use Reference to look up a feature by name and the Glossary to look up a word.

Colour roles

Each colour below has a job. This key, called a legend, shows the labels you’ll see throughout the docs.

Green marks tools included in a standard DocForm page. Blue marks tools you can choose to add. Purple marks something to try on the page, yellow marks a tip, and red marks a caution.

Start with hierarchy

Notice how your eye lands on the page title, then on the section headings, and then on the text beneath them. That order is called visual hierarchy. DocForm uses size, spacing, and colour to make it easy to see where to start and what belongs together.

After the orientation, visit Visual hierarchy: guiding the eye and The signal ladder in Design with hierarchy before browsing the feature guides. Those pages show how to give each page a clear starting point and make the most important parts stand out.
