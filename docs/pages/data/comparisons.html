Read a matrix on one colour scale

Each cell combines one row and one column. A shared colour scale means the same shade represents the same value anywhere in the grid for the selected measure. In the percentage view, every cell uses the same zero to 100 scale. In the count view, the scale follows the smallest and largest counts in the grid.

The source supplies the counts and percentages. A missing value is labelled Missing, while zero is shown as a number. A cell cap keeps very large grids from opening all at once. When a grid exceeds its cap, OffPrint keeps the readable starting table.

Try it

Choose Next variant to compare a short contents list with the outline off. The summary names both changed conditions. Look for the estimated time, its bounds, and the paired change from the baseline.

The baseline is the starting setup. A variant changes one condition, or several when comparing whole configurations. The selected variant and baseline share a chart scale for each unit, and that scale holds when you switch variants.

An interval gives lower and upper bounds for an outcome estimate. A paired difference measures a change using matched cases, such as the same readers trying each setup. Here, the example data supplies that difference and its own bounds. A negative change in seconds means a shorter time.

When to reach for it

Use a matrix to scan many combinations at once. For a risk matrix with zones and placed items, or a confusion matrix with derived totals, shares, precision, and recall, use a risk or confusion grid instead. Use a scenario comparison to explain what changed from a specific starting point. Let the matrix shading or the comparison bars carry the emphasis in its section.

For every reader

Use Tab to reach the measure and variant menus. Numeric labels and the change summary remain readable in either theme. Wide tables scroll sideways on a phone. Print the selected measure or variant you want to share. With scripts off, the starting tables show the counts and all three setups.
