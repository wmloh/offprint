Local file dropzones

A dropzone lets a reader open a file from their own computer and see it inside the page. Nothing is uploaded, so the file never leaves their computer.

Each box lists its accepted file types and size limit. Dropzones can read CSV, TSV, JSON, YAML, XML, and Markdown, with narrower choices where a view needs a specific format. If a file is rejected, the status explains why and any previous accepted data stays in place.

When to reach for it

Use a standalone preview to inspect a file, an override to try it in one view, or a shared replacement when several views should update together. Label the destination next to the file picker so readers can predict which views will change.

For every reader

Choose a file and Reset are keyboard-accessible alternatives to dragging. A phone’s picker can open a file saved on the device. The controls follow the page theme, and the starter tables and download links stay visible with scripts off. Print the view after loading the file you want to show.
