Small multiples and scatter-plot matrices

Small multiples split one chart into a grid of little charts, one per group, all drawn on the same scales so you can compare them at a glance. A scatter-plot matrix does the same for several measurements at once: it plots every pair of them against each other.

See it

Try it

Move along any panel: a cursor shows the same week in all three. Drag across one panel to narrow the weeks, and the other two follow; Reset range brings them back. Then click the Children chip to hide that line everywhere at once.

Same scales, fair comparison

Small multiples only work when every panel is measured the same way. OffPrint looks at the data of all the panels together and gives them one shared x axis and one shared y axis. A busy site and a quiet one then sit on the same ruler, and the difference between them is visible instead of hidden by each panel stretching to fit.

Sometimes the shapes matter more than the sizes, for example when one group is ten times larger than the rest. Then ask for a free y axis: the x axis stays shared and each panel scales its own values. Say so in the caption, because readers will assume the scales match.

You can split by any field your points carry, such as site, region, or experiment, or simply give each series its own panel. Panels can be any chart type, including bar charts, heatmaps, and histograms, in two to four columns.

Every pair at once

Try it

Drag a rectangle around the tallest plants in any plot. Every other plot dims the plants outside it, so you can see where the same plants sit on the other measurements. Clear brush removes it. Click a single dot to select that plant, and it lights up in all twelve plots.

Read the matrix

Each row shares one measurement on its vertical axis and each column shares one on its horizontal axis, so the plot in row 3, column 1 shows stem height against leaf length. The plots above and below the diagonal are mirror images. The diagonal itself names each measurement with its range, and can show a small histogram of it, counted straight from the data.

Up to four measurements fit in the page with full axes. With five or six, the plots inside the page drop their tick labels to stay readable; open the figure in the zoom view to see every axis in full.

From a data file

Both layouts can read a named data source. For small multiples, map the columns as you would for a single chart and name the column to split by; each panel gets its own rows. For a matrix, list the columns to compare, the column that names each record, and optionally a column that colours records by group. When the source changes, the panels redraw together.

When to reach for it

Use small multiples when one chart would need too many crossing lines, or when the question is “is this pattern the same everywhere?”. Use a scatter-plot matrix early in an analysis, to spot which measurements move together, or in a report to show the relationships behind a conclusion. Both are strong signals and take space, so keep the panels few, and point out in the text the panel or pair that matters.

For every reader

Each panel reads its values with the arrow keys, like any OffPrint chart, and keyed points can be selected with Enter. Escape clears a matrix brush, and the status line says how many records it holds. Choose Table to list every value: small multiples show each panel’s table, and a matrix shows one table of records with a column marking the brushed ones. With scripts off, the written summary table stays readable.
