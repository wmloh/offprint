Sankey diagrams

A Sankey diagram shows how an amount splits and merges as it moves through stages. Wider ribbons carry more.

See it

Try it

Point at Storage to trace the paths that reach it and leave it. Point at the ribbon from Solar to Storage to read 42 kWh, about 68% of solar output and 70% of storage input. Select that ribbon, then choose Table to find the same highlighted flow in the Links table.

Read a difference in totals

Storage has a dashed outline. It received 60 kWh in this period and sent out 55 kWh. The readout shows the 5 kWh difference so you can compare it with the underlying measurements. A starting or ending node can have flows on just one side.

Draw flows from records

Give each link a starting node, a destination, and an amount in a common unit. This example reads a named data source with one row per flow. OffPrint places stages from left to right and orders nodes within each stage to reduce crossings. You can also set the columns and order yourself.

Read by keyboard or table

Tab to the plot and use the arrow keys to read nodes from left to right, then read individual links. Press Enter or Space to select a node or link in the energy example. Table view lists the same totals, differences, and shares in text. The written tables stay available when scripts are off or the data includes a loop. Interactive export restores the selected key.
