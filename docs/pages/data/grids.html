Risk and confusion grids

A grid chart lays out two ordered lists as rows and columns, such as a risk matrix that places each risk by how bad and how likely it is, or a confusion matrix that counts how often each true class was predicted as each class. Each cell can hold a value, a coloured zone, and the items that sit there.

See it

Try it

Move over dot 1, then follow its dashed line back to where it started. Click a dot to select that risk. Then click the chart and use the arrow keys to walk the cells; press ] to step through the risks in a cell.

Rows, columns, and what sits in the cells

You list the rows and the columns in the order they should read. For a risk matrix, list impact from worst at the top to mildest at the bottom, and likelihood from rarest at the left. Each cell can carry a number you supply, a set of items, or both. Items are packed into their cell as small numbered dots. When a cell fills up, the last dot becomes a count of the rest, and every item still shows in the readout and the table.

Colour cells by zone

A zone gives a group of cells one colour and one name, such as High or Low. You can list a zone’s cells yourself, or give it a score range. With score ranges, each row and column gets a rank, counting up from the bottom row and the left column, and a cell’s score is the two ranks multiplied or added together. The first zone whose range holds the score claims the cell. Listed cells always win over score ranges, so you can carve out an exception.

Read a confusion matrix

Try it

Choose Row shares. Each row now adds up to 100%, so you can read what happened to every true fox. Then choose Column shares to read what the classifier meant each time it said fox.

Each row is a true class and each column a predicted class, so the diagonal holds the correct answers. OffPrint works out the totals, the shares, and two rates from the counts you supply. Recall, at the right, is the share of each true class that was found. Precision, along the bottom, is the share of each prediction that was right.

From a data file

A grid can read a named data source. Records with a row, a column, and a value fill the cells. Records with a row, a column, and an item name place items, with two optional columns for the cell an item moved from. Rows and columns you have not listed appear in the order they first turn up, so list them when the order matters.

When to reach for it

Use a risk grid when readers should see at a glance which risks need attention, and use the trails to show what your fixes changed. Use a confusion grid when the mistakes matter as much as the score. To compare several supplied measures in one table, such as counts and percentages side by side, an evaluation matrix fits better. Zones and strong colours are loud, so keep one grid per section.

For every reader

The arrow keys move from cell to cell, and the readout names the cell, its zone, its value, and the items in it. [ and ] step through a cell’s items. The normalization chips work with the keyboard like any other chips. Choose Table for the same grid as text, with a second table that lists every item. A grid can also follow a step sequence, so items and zones appear one step at a time. With scripts off, the written table stays readable.
