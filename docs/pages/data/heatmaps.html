Heatmaps

A heatmap colours every cell of a grid by its value, so high and low regions stand out before you read a number. It can also draw contour lines through equal values, like the height lines on a hiking map.

See it

Try it

Move over the cells to read each score. Then drag along the colour scale beside the grid, from about 90 up to 100. Cells outside that range fade, which leaves the most comfortable region. Choose Show all values to bring the others back.

Rows, columns, and cells

Each row and column is one setting, and each cell holds the value where they cross. The grid can come from a written table or from a named data source with one record per cell. A missing value leaves its cell blank instead of guessing. A grid can have up to 5,000 cells, which is about 70 rows by 70 columns.

Choose a colour scale

A sequential scale runs from pale to strong in one colour, as in the comfort grid above. A diverging scale uses two colours that meet at a neutral middle, so rises and falls read as opposites. A log scale suits values that span many powers of ten. All three use the site’s own colours and stay readable in light and dark mode.

Try it

Find the strongest blue cell, then click a single step on the colour scale. Only cells in that step stay bright. Click the same step again to clear it.

Contour lines

Contour lines connect places with the same value, so a ring of lines marks a peak and closely spaced lines mark a steep change. They need a complete grid whose rows and columns are numbers in order, like text sizes and line lengths. On a grid of names, such as days and sections, DocForm skips the lines and draws the colours alone.

Filter by value

The colour scale beside the grid doubles as a filter. Drag along it to keep a range of values bright, or click one step to pick out that band. The legend names the chosen range and offers a button to show all values again. The table view always lists every value.

When to reach for it

Use a heatmap when the question is “where in this grid is it high or low?” Colour is a loud signal, so give the heatmap its own section and keep nearby callouts and tags to a minimum. For exact comparisons between a few numbers, a bar chart or a results table is easier to read.

For every reader

Tab to the grid and use the arrow keys to move between cells. Page Up and Page Down pick a band of values on the scale, and Escape clears it. Cells fade in as the grid enters view, except under reduced motion. Choose Table for exact values on a phone or in print. With scripts off, the written table stays readable.
