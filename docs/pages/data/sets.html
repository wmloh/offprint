Venn diagrams

A Venn diagram shows which items belong to two or three groups. Each number counts the items in just that region, and circle size is schematic.

See a subset and a separate group

All reviewed samples came from the current collection, so their circle sits inside it. The reference samples came from a separate collection. When two groups contain the same members, their labels share one circle.

Try it

Hover inside the green circle to see the reviewed samples. Click the region to select it, then open Table to find the same highlighted row.

Draw from counts

This named data source has one row per populated region. In this survey, the joint session consists of exactly the people who attended both workshops. That overlap has a lens shape. The diagram uses a familiar three-circle layout with hatched regions wherever the count is zero.

Read by keyboard or table

Tab to a plot and use the arrow keys to read its regions. Press Enter or Space to select a region in the sample example. Table view includes zero counts. Interactive export restores the selected region.
