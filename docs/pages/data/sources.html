Named data sources and data views

A named data source holds a table or list of values once and feeds it to many views on a page. Data views show those raw values as a table, as text, or as a tree.

Three ways to read the same data

A named source holds the records, or individual entries. Each view reads that source and chooses how to display it. A table lines up fields for comparison. A code view keeps the original text, including commas and line breaks. A tree opens each record to show its fields.

Try it

Open the first branch in the tree and find the group name and count in both views.

Sources can come from CSV or TSV (a table stored as text, split by commas or tabs), JSON, YAML, or XML (text that can hold lists and nested fields), Markdown (formatted notes), or values supplied directly to the page. In automatic mode, Markdown appears formatted and rows with matching fields appear as a table. Nested values appear as text unless the author asks for a tree.

Limits and unreadable data

A size cap can hold back a large preview until you choose Show anyway. A row cap loads a table in batches. A parse error means DocForm could not read the structure of the data. In a raw view, the error appears next to the original text.

Try it

Choose Show anyway, then find the spot where the broken example leaves the reference count blank.

Replace one view

A local override changes just its target. Reset brings that view back to the latest shared source. A shared replacement updates all its views together when each can read the incoming records. If any view rejects the replacement, the previous data stays in place.

Try it

Load the sample and return to the first table to see the two replacement rows. Compare it with the unchanged text view, then choose Reset at the dropzone.

When to reach for it

Use a named source when readers need several views of the same records. When a chart carries the story, put the raw view below it so readers can check exact values at their own pace.

For every reader

Tab reaches Show more and the file picker. On a phone, wide tables can scroll sideways within the reading column. The table uses the page theme and the original counts remain readable in the first table with scripts off. Load all the rows you want before printing.
