Data trees

A data tree shows nested information as branches that open and close. Readers can expand everything at once or explore one branch at a time.

Try it

Open loads under reading, then choose Show more inside that list to reveal the next group of features.

What opens and what stays folded

Tree depth is the number of levels that start open. This tree opens one level, so you can see the lists under each profile. Press Expand all to open the visible branches, or Collapse all to fold them back to the top level.

The cap applies to each list separately. For example, an open list in the first tree shows four children at first. Show more adds another batch in that list.

Try it

Expand the first numbered branch to find its group and reference count. Collapse all to close it again.

When to reach for it

Use a tree when the nesting matters, as it does for settings and their lists. Start with a shallow depth so readers see the main branches before the details.

For every reader

Use the up and down arrow keys to move through rows, and the right and left arrow keys to open and close branches or move between levels. On narrow screens, open the branch you need. The tree follows the page theme. Expand the lists you want before printing. With scripts off, the summary and source table links remain readable.
