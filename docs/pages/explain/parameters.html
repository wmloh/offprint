Parameters and presets

Parameters are sliders, menus, and switches that change the values a page shows. Presets set several of them at once with one click.

A live value can show a single setting or calculation. A live text template keeps the surrounding words and fills several places with current values. The fixed-value line above uses a single value, and the plan sentence uses a template. A preset changes its listed settings together and is marked when those values are active.

Share settings within a scope

Try it

Move the first slider and check the reading plan above. Now move the other slider. The reading plan stays as it was.

A scope is a named set of parameter definitions and their current values. A definition gives a setting its type, starting value and any bounds or choices. The same setting can appear in several places within a scope. Separate scopes can use the same setting name for independent values.

When to reach for it

Use parameters to let readers change one assumption and see its effect. Presets give them useful starting combinations without asking them to set every control first. Put the changing value near its controls when the connection matters.

For every reader

Use Tab to reach each control. Arrow keys move the slider and choose a pace. Space toggles a switch or checkbox. The controls can wrap on a narrow screen and follow the page’s theme. In print the plan sentence shows the current values. With scripts off it shows the written starting values.
