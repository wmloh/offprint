Parameters and presets

Parameters are values readers can change with sliders, menus, and switches. Presets set several of them at once with one click.

A live value can show a single setting or calculation. A live text template keeps the surrounding words and fills several places with current values. The fixed-value line above uses a single value, and the plan sentence uses a template. A preset changes its listed settings together and is marked when those values are active.

Share settings within a scope

Try it

Move the first slider and check the reading plan above. Now move the other slider. The reading plan stays as it was.

A scope is a named set of parameter definitions and their current values. A definition gives a setting its type, starting value and any bounds or choices. The same setting can appear in several places within a scope. Separate scopes can use the same setting name for independent values.

Chips and searchable lists

Short lists of choices appear as chips: small rounded buttons that show every option at once, like the pace and tools above. A list with more than seven choices, or with long names, becomes a combobox instead. You type to narrow the list and pick from what remains. Authors can choose either look for any control. Every press sends a soft ripple across the chip, and chart legends, table filters, variant choosers and measure choosers use the same chips.

Try it

Click the field and type chart to narrow the list, then choose Heatmaps. Remove a chip with its small cross, or press Backspace in the empty field. Use All and None to change every choice at once.

Link controls to the page

A parameter can do more than fill in text. Without any extra page code it can show or hide a block, highlight a matching item elsewhere, or change how a chart is drawn.

Show a block for some choices

The review and search steps in the first demo appear only while their choices are on. A block can depend on a switch, a chosen option, or a calculation. It fades in and out as the choice changes. With scripts off, every such block stays visible, so nothing is lost.

Drive a chart’s settings

A slider or a choice can change a chart directly: its number of bins, the position of a reference line, which series are shown, the visible range, the top of a colour scale, or the direction and stacking of bars. Try the bar layout choices and the bin slider on the charts page. If a value would break the chart, the control springs back to its last working value.

When to reach for it

Use parameters to let readers change one assumption and see its effect. Presets give them useful starting combinations without asking them to set every control first. Put the changing value near its controls when the connection matters.

For every reader

Use Tab to reach each control. Arrow keys move the slider and move between chips, and Space toggles a switch or a chip. In a combobox, type to filter, use the arrow keys to move through the list, and press Enter to choose. The controls can wrap on a narrow screen and follow the page’s theme. In print the plan sentence shows the current values. With scripts off it shows the written starting values.
