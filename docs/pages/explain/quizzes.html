Quizzes

A quiz starts as a small card with its number, a short description, and tags. Readers open it when they are ready and answer one question at a time. A results card then shows how they did.

See it

Try it

Press Start. Pick an answer to the first question, then press Check to lock it in and see how you did. Open the hint first if you like, but it halves that question’s score. Press Hide to fold the card away; the stopwatch stops until you resume.

Stack several quizzes

A stack holds several quizzes that readers take in order inside the same card. When they finish, a results card appears below with a small bar chart. Switch its view to see the time per question, the score per quiz, or the average score and time for each tag.

Question types

  • Single choice is the default. Mark the right option with "correct": true.
  • Multiple choice ("type": "multi") gives part marks: each right pick adds and each wrong pick takes away.
  • Fill in ("type": "fill") puts [[name]] blanks in a sentence or a code block. A blank with options becomes a dropdown; any other blank is a text field.
  • Matching ("type": "match") asks readers to drag lines between two columns. Extra items on the right make it harder.
  • Your own type can be added with a short script. It gets the stopwatch, hints, feedback, and results like the built-in types.

Write a quiz

Put a small quiz straight in the page inside the quiz block. For larger sets, keep each stack in its own .json or .yaml file so you can edit the questions without touching the page.

  1. Save the stack, for example as assets/data/week-1.json.
  2. Add it to the site manifest under assets.data, with a name and a generated output file.
  3. Run the offline asset tools to create the wrapper script.
  4. Turn on the quiz and data features and write <div data-op-quiz="Week 1"></div> where it should appear.
{
  "title": "Week 1",
  "feedback": "end",
  "stopwatch": true,
  "quizzes": [
    {"title": "Lenses", "tags": ["domain:optics"], "draw": 5, "questions": [ … ]}
  ]
}

Settings set on the stack apply to every quiz, and a quiz or question can override them:

feedback
"end" shows answers in the results, "question" shows them after each question, and "none" never shows them
stopwatch
Shows a timer that counts up but never stops anyone answering
hint, hintPenalty
One or more hints per question, and how much each one used lowers the score
shuffle, draw
Mix up questions or options, and pick a few questions from a larger bank on each try
scoring
"partial" gives part marks; "all" needs every part right

For every reader

Choice options, dropdowns, and text blanks work with the keyboard. Matching is drag only. Results stay in this page visit until the reader presses Retry or reloads. In an Interactive export, readers can take the quiz just as they can here. A Reader export shows the questions as a printed sheet, without answers.
