Linked selection

Linked selection highlights matching items across text, charts, and tables when a reader picks one. It can remember the choice from page to page.

Try it

Choose Search in the first set. Both sets below follow. Choose Outline in the third set. The middle set and the highlight follow, while the first set stays on Search. Change the middle set by itself to see that it sends no choice back.

How a group shares choices

Publish
Send your choice to the group and keep control of your own view.
Follow
Receive the group’s choices. Your own local changes stay local.
Both
Send and receive choices. This is the default for linked controls.

A selection key is the shared name for an item. It lets a tab, point or row refer to the same thing even when their visible labels differ. Prose, rows and shapes can simply highlight the choice without becoming controls.

Pick a starting choice

A startup seed is a control’s offer to start the group on its current item. The publish-only set above offers Outline, so the other sets start there. An explicit group starting choice takes priority. Otherwise a remembered choice that still belongs to the group takes priority over a seed. With none of these, the group starts clear.

Try it

When to reach for it

Use linked selection when the reader needs to recognise the same item in several views. Follow mode works for companion views. Keep groups separate when their choices refer to different things.

For every reader

The demo tabs respond to Tab and the arrow keys. The highlighted line stays in the same place on a narrow screen and uses the page’s theme colours. Printed and script-free pages keep the item labels so readers can match them without live highlighting.
