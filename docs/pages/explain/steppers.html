See it

Try it

Press Next. The calculation changes, and the Layout point and row are highlighted. Click the Reading point to jump straight to that step. Use Reset to return to the opening step.

One step, several views

The stepper shows one item of an ordered example and reports where you are, such as Step 2 of 3. Previous and Next move in order. Reset restores the author’s chosen starting step, which is the first step here.

The companion calculation switches with the current step. The chart and table use linked selection to mark the same item. All the rows and points stay visible, so readers can compare the selected value with the others.

Use the same step controls elsewhere

Figure steps, chart tours, SVG animations, stepped pipelines, and scenario comparisons share the stepper’s navigation. Give items matching data-df-key values and put the same data-df-selection-group on the components to move them together. Use data-df-initial to choose where Reset goes.

In a page script, DocForm.sequence.get('reference-count') gives you the controller. Call select('reading') to jump to a step, or listen for df:step on the list to run code when the current step changes.

When to reach for it

Use a worked-example stepper when each operation builds on the last. Keep a shared chart or table in sight when the reader needs the whole sequence for context. Put any instructions that apply to every step before the controls.

For every reader

Use Tab to reach Reset, Previous and Next. The ends keep keyboard focus and prevent further movement. On the focused chart, move between points with the arrow keys and press Enter or Space to choose one. Use the chart’s Table button to read the same values as rows.

The views stack on a narrow screen and use the page’s theme. The printed example shows the current step. With scripts off, the complete ordered list, companion calculations, and chart data table are visible.
