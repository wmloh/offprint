Recipes

Present and publish a site

Turn a set of pages into a site people can find their way around, present from, and use offline. This recipe combines navigation, search, the glossary, themes, roles, and zoom tools.

The goal

Share a DocForm site that readers can explore on their own and that you can present from a single screen. An offline copy opens on the reader’s device without an internet connection.

Give readers a route through the site

These docs put orientation first, group the feature guides by goal, and collect worked examples under Recipes. The Navigation sidebar at the left lets you move between pages. The outline, a list of headings on the current page, gets you to the right section.

Try it

Find this recipe in the sidebar. Open Search with the magnifying glass or press S, then look for The signal ladder in the results. Open the Glossary and find “visual hierarchy” for a definition you can use across the site.

Give pages names that will make sense out of context in search results. Add terms to the glossary when readers will meet them on several pages.

Keep meaning consistent

Try it

Switch between light and dark. Check whether the role labels and the figure below still read clearly. A role gives a colour a job, and the label carries that meaning in either theme.

Show one figure on the big screen

Try it

Open the drawing with a click, or focus it and press Enter. In Figure zoom, try the laser pointer to indicate Start here, or use the magnifier to enlarge a label. Press Esc to return to this section.

Zoom tools give the presenter a way to point, enlarge, mark, or measure a detail while the figure fills the screen. Keep the caption useful for someone reading on their own.

Prepare the offline copy

The offline asset tool checks the prepared files a site needs. A search index is a saved list of page titles, headings, and text that search can use across the whole site. The tool also prepares separate data files so charts and tables can open their data offline, a feature called Data file wrapper.

  1. Open the tool in a browser that supports choosing a site folder. A folder is the container that holds the site’s pages and supporting files.
  2. Choose the folder and check the report. Current means the prepared file is up to date. Missing means it has yet to be created. Stale means a page or data file has changed since it was prepared. A blocked item needs the issue shown beside it resolved first.
  3. Rebuild missing or stale items, then reopen the site and check a search result on another page and a figure that uses prepared data.
  4. Share the pages, supporting files, and DocForm library together, keeping their folders in the same arrangement. Have the reader open the welcome page from the copy on their device.

Try it

Open the asset tool and find its folder chooser. If you have a site folder handy, choose it to inspect the report before deciding whether anything needs rebuilding.

Features used

  • Navigation, Search, and the Glossary help readers find pages, passages, and definitions.
  • Colour roles and Theme keep the site readable and its accents consistent.
  • Figure zoom and Zoom tools give a presenter room to work with a figure.
  • The offline asset tool prepares the Search index and data files for sharing.
