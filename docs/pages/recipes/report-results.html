Report results

Present measured results so readers can check them and explore them. This recipe combines named data, charts, playback, results tables, comparisons, parameters, and dropzones.

Goal
Share results readers can check and explore
Combines
Named data sources, SVG charts, guided chart playback, results tables, evaluation matrices, scenario comparisons, parameters, file dropzones
Reading time
About 10 minutes

The goal

Show how the 54 references in a snapshot of DocForm’s library are distributed across five groups. A reader should be able to check a count, compare groups, and see how much a shorter reading plan would cover.

Start with counts readers can check

Try it

Clear Reading and Interaction in Groups to show. Their bars and rows disappear together. Sort the table by References to compare the remaining groups, then select all five again.

Use Named sources and data views to give several views one named set of records. Here, the SVG chart and Results table both read Reference counts. Parameters let the reader change a setting, in this case which groups both views show.

Show how the total builds

Try it

Use Play to watch the count build, or use Next to move between notes one at a time. Guided chart playback gives each note a point where it can explain what changed.

Try it

In the Evaluation matrix, change Reference count to Share of all references. In the Scenario comparison, choose All groups to compare it with the starting plan, Setup and Layout. The matrix shows proportions at a glance. The comparison tells you which groups account for the difference.

Load a different set of counts

Choose or drop a CSV file, a small table saved as plain text.

Try it

Download the Setup and Layout sample, then choose it in the File dropzone. The chart and results table both show just those two groups, subject to the selections above. Press Reset beside the file chooser to restore the original counts.

The dropzone replaces the shared source for the current page. The playback and plan comparisons use the original snapshot so their notes and totals stay together.

Features used

  • Named sources and data views feed the SVG chart and Results table. Parameters filter both.
  • Guided chart playback shows how each group contributes to the total.
  • Evaluation matrices and scenario comparisons show what each plan covers.
  • File dropzones let readers supply their own data.
