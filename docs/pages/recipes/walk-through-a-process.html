Walk through a process

Guide a reader through a procedure one step at a time. This recipe combines steppers, card panels, tabs, annotated code, and linked selection.

Goal

Combines
Worked-example steppers, card panels, tabs, code, linked selection
Reading time
About 10 minutes

The goal

Take a reader through revising the headings of a sample OffPrint page. The finished outline should tell someone where to start, how to move around, and how to find a section.

Follow the revision

Try it

Point at a circled number in Draft or focus it with Tab to see its annotation, a note about that line. Press Next and find the minus and plus in Changes. That view is a diff, which shows what was removed or added. Choose Finished outline directly and watch the stepper catch up.

The worked-example stepper sets the order. Tabs let readers jump straight to a view they want to revisit. Linked selection keeps both controls on the same stage. The Code feature displays the exact draft text, annotations, and changes. Here it displays heading text from the example.

Keep reusable checks nearby

Try it

Choose Check the order and compare it with the finished outline above. The procedure stays where you left it.

Features used

  • Worked-example steppers, Tabs, and Linked selection connect each stage with its view.
  • Code shows the draft with annotations and the changes in a diff.
  • Card panels keep reusable checks close to the worked example.

Hierarchy walkthrough

Loud
The active tab and the lines marked added or removed show the reader where to look for the current change.
Strong
The stepper, tab panels, and code blocks give each stage a stable place. The separate card panel groups the checks that apply throughout.
Quiet
Short directions and captions explain how to read each view and leave room for the draft and its changes.
