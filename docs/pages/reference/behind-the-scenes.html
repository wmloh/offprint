Behind the scenes

A plain-words look at what happens when a DocForm page opens. It covers the settings and checks an agent works with on your behalf.

Use it to
Understand what an agent sets up for you
Reading time
About 10 minutes

Profiles and dependencies

A profile is a starting set of features.

The reading profile is the usual choice. Your agent can add or turn off features to suit a page. A feature that another one needs is called a dependency. DocForm automatically includes dependencies, so asking for Zoom tools also brings in Figure zoom.

See the feature directory for the reading defaults and what each feature needs.

Site and page settings

The site settings, also called the manifest, hold shared choices. They give the site its title and page order, choose a glossary page, and keep lists of terms, sources, and reusable controls. They also describe which prepared search and data files the site uses and where those files belong.

Page settings apply to a single page. This page adds TeX math for the formula below. The other reference pages use the same site settings and keep their own feature choices.

Startup and ready stages

  1. Load. DocForm reads the settings and opens the selected features and prepared data from the site folder.
  2. Set up. The page can supply its own material, such as the values that will feed a chart.
  3. Build. DocForm applies the features to the page, for instance by drawing the chart and adding its controls.
  4. Ready. The page can now use the finished chart, for example to read which series it displays. DocForm reaches this stage even when it can recover from a problem along the way.

Problem reports

DocForm collects problem reports as the page opens and as readers use it. It also lets the page know when each report arrives. Your agent can inspect the collected reports. Some features show a message right beside the problem, as in the unreadable data example.

Bundled maths and data readers

TeX math comes with KaTeX to lay out formulas. DocForm also includes js-yaml to read YAML, a way of saving named values and lists in a text file. Both helpers work offline. The file dropzones guide has a YAML sample you can open on the page.

Starter settings

The starter settings template gives your agent a shared settings file to copy and adapt. It includes the reading profile, a sample page list, and examples of colour roles, definitions, and sources. Your agent replaces the examples with your site's title, pages, and content.
