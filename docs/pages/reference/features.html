How to read the directory

“On by default” means included with the standard reading setup. “On request” means added for a site or a page when needed. Features still need something to work with, such as the data for a chart.

The signal ladder explains how strongly each feature draws the eye. “Needs” lists what must be in place and names a few extras that add abilities. The profiles guide explains how DocForm brings in required features.
