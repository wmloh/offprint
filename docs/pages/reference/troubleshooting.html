Common symptoms

Start with what you can see. If you have the page as a file, open it in a browser from the original site folder so it can find the files beside it.

What you seeWhat to check
Plain text and default-looking headingsMake sure the site folder has been unpacked and the DocForm library folder came with it. See opening a site.
Text looks right, but the controls do nothingOpen the original page in a browser rather than a file preview. Ask the agent to check whether the browser ran the page's scripts.
A single feature is missingCheck the feature directory to see whether the feature is on request and what it needs. Ask the agent to check the page settings.
A chart or figure is blankAsk the agent to check that its image or data is present, the data can be read, and any prepared copy is current. If a file dropzone changed the view, try Reset.

Problem reports

A problem report may appear beside a broken view. Copy the wording or take a picture of it. Include the page title, the section, and what you did just before it happened.

Some reports are recorded in the browser console. If the page shows no message, give your agent the same details and ask for the recorded reports to be checked. See what a report can contain.

Stale search or glossary

If search finds a new phrase on its own page but misses it from other pages, the site search index may be stale. A glossary entry can also show its shared definition while its Used on links miss new pages or still point at renamed sections.

Ask your agent to regenerate the search index with the offline asset tool. Then reopen the page and try again. See how the tool prepares the index. If a shared definition itself is wrong, ask the agent to check the site settings too.

Pages from older DocForm versions

Older pages may have been built for a different version of DocForm. If a feature stops working after the library is replaced, ask your agent to update the page and its settings to work with the new version. Give them the original site folder and an example of what changed so they can check the result against the original.
