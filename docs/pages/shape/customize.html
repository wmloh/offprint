Design tokens

Design tokens are named settings for details like text colour, spacing, and width. Change a shared token and the parts of the site that use it change together.

What tokens can change

Fonts, spacing, and corners

The font settings choose the shape and size of letters and the space between lines. The spacing scale is a set of repeatable gaps. Corner radius sets how rounded a corner is. Eyebrow and labelled-field settings also control the size and weight of small labels and how much room they get.

Reading and figure widths

Reading width limits the length of a line of text. A figure width limit can make large blocks like figures and tables narrower inside that column. Separate settings set the gap at the sides of the page and the starting width of the sidebar.

Section cycle and line

Try it

Trace the lines beside the main headings on this page, then compare them with the section lines guide. The cycle picks the order. Separate settings control how thick the line is, how strong its colour looks, and how far it sits from the text.

Surfaces, links, and chart colours

The colour guide shows the nine named text-and-background pairs that roles use. Text, borders, and interactive details like the outline around a focused control have their own settings too.

When to reach for it

Tune tokens when several pages need to share one look, or when readers need more legible text or shorter lines. Make the change where it belongs. A shared setting suits the whole site, while a local setting suits a single sample or section. Keep the shades of headings, bold words, and italics close enough to the main text colour that role colours can still stand out.

For every reader

Check both themes, a narrow screen, and a printed page when you change the look. The samples stack on narrow screens. Their colours, type, spacing, and widths still show with scripts off. The custom section cycle needs scripts, so the short heading marks then use the default cycle.
