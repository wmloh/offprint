Open a DocForm site

You can open a DocForm site straight from your computer. Follow these steps to find the first page and open it in the same app you use to view websites.

Reading time
About 5 minutes

Open these docs from your own computer

Files and folders

A file is one saved item, such as a page or picture. A folder holds files and can hold other folders, too.

A DocForm site comes with page files and supporting files that provide things like pictures, colours, and controls. Keep the entire set together, with each file in its original folder. If you received it as a ZIP file, a single file packed with other files, use your computer’s Extract or Unzip command first, then open the unpacked copy.

Open a page from disk

  1. Open the app you use to browse files and folders, such as File Explorer on Windows or Finder on a Mac. Find the unpacked site where you saved it.
  2. Find the starting page inside the site. It is often called index.html, or just index if your computer hides the end of file names. For this guide, choose the starting page inside the documentation folder.
  3. Double-click the starting page. If it opens in a text editor, right-click the file, choose Open with, and select your browser, such as Chrome, Edge, Firefox, or Safari.
  4. Look for the page title and the navigation panel. The address bar, the box near the top of the browser window, will usually show a local file address. The browser opened a saved file on your own computer, which is what from disk means.

Working offline

Offline means without an internet connection. The browser reads each page and its supporting files directly from your computer, so you can still follow links between the saved pages and use their DocForm controls. A link to an outside website still needs a connection.

When a page looks unstyled

If you see plain text with little spacing or colour, or the reading controls are missing, the page may be missing some of its supporting files.

  1. Open the page from inside the unpacked folder. Opening it inside a ZIP preview or copying out just the page can leave its supporting files behind.
  2. If you moved or renamed files, try opening a fresh copy of the complete site with its folders arranged as supplied.
  3. Reopen the starting page in your browser. If the controls are still missing, check whether the browser allows scripts, the small programs that make the controls work. If the settings are managed for you, ask the site’s author or your agent to help check the copy you received.
