Open an OffPrint site

You can open an OffPrint site straight from your computer. Follow these steps to find the first page and open it in the same app you use to view websites.

Reading time
About 5 minutes
You will
Open these docs from your own computer

Files and folders

A file is one saved item, such as a page or picture. A folder holds files and can hold other folders, too.

An OffPrint site comes with page files and supporting files that provide things like pictures, colours, and controls. Keep the entire set together, with each file in its original folder. If you received it as a ZIP file, a single file packed with other files, use your computer’s Extract or Unzip command first, then open the unpacked copy.

The way an agent arranges those folders is called the site structure: pages in one folder, the OffPrint library folder beside them, and shared settings and data in predictable places. Keeping that layout lets every page open offline and lets the export button find everything a page uses.

Open a page from disk

  1. Open the app you use to browse files and folders, such as File Explorer on Windows or Finder on a Mac. Find the unpacked site where you saved it.
  2. Find the starting page inside the site. It is often called index.html, or just index if your computer hides the end of file names. For this guide, choose the starting page inside the docs folder.
  3. Double-click the starting page. If it opens in a text editor, right-click the file, choose Open with, and select your browser, such as Chrome, Edge, Firefox, or Safari.
  4. Look for the page title and the navigation panel. The address bar, the box near the top of the browser window, will usually show a local file address. The browser opened a saved file on your own computer, which is what from disk means.

Working offline

Offline means without an internet connection. The browser reads each page and its supporting files directly from your computer, so you can still follow links between the saved pages and use their OffPrint controls. A link to an outside website still needs a connection.

Export a standalone copy

Use desktop Chrome with JavaScript enabled to export from a local OffPrint page. Choose Export in the top-left reading controls, or at the bottom of the page when those controls are hidden. Then choose the site folder, which holds the pages and their pictures and data. Chrome may ask to upload the files. OffPrint reads them on your computer and includes the library styles and fonts automatically.

  1. Choose an export mode. Reader is the default. It keeps the captured view and lets you try supported figure steps. Interactive also runs supported cards, animations, diagrams, charts, and their linked controls. A page that cannot start interactively opens in its Reader view.
  2. Select the pages or groups you want. For a single-page report or results summary, select its one page.
  3. Choose Build preview. The open page uses its current selections. Other pages use saved reading choices when available and still valid, or their starting view. The preview lists the views used, imported content, missing assets, unavailable links, and the exact file size.
  4. Interactive includes site-provided data needed by supported controls. To embed a full file you imported, select it under Include full imported datasets. Each choice shows the file size and where it is used. If you leave it unchecked, pages that need it use their Reader view, which can still show already rendered content from the file.
  5. To include a local page script, use Include local author scripts. The preview shows the page, any required files, and missing dependencies. Select only scripts you trust. They run automatically in the download when their page opens. Review the choices and build a new preview after changing either set of checkboxes.
  6. Choose Download HTML. You can move the file by itself and open it from disk in Chrome with JavaScript enabled. Use the sidebar or the arrows beside the reading controls to move between pages. Hover over, focus, or tap an annotated term to see its definition.

The top-left reading controls show your progress and let you open navigation (N), toggle focus mode (F), switch theme (T), and jump between headings (J and K). On desktop, drag the sidebar edge to resize it, or press N to cycle shown, hidden, and auto-hide. In auto-hide, move the pointer to the left edge. On narrow or touch-only screens, navigation opens as a drawer. Press Escape or tap outside it to close it.

In Reader, use a supported figure’s step picker or the buttons beside it to change the drawing and read each step’s details. Charts and other interactive examples show their captured view. In Interactive, changes you make to supported controls carry over when you return to the page in the same open copy. In either mode, Chrome’s Back and Forward buttons revisit pages and sections. Links to omitted pages are disabled, and outside links still need an internet connection.

To keep imported values out of a new export, reset imports on the open page and use Clear saved views and imports under Saved reading data. Clearing deletes this site’s saved choices and imports from this browser, so sibling pages use their starting views.

When a page looks unstyled

If you see plain text with little spacing or colour, or the reading controls are missing, the page may be missing some of its supporting files.

  1. Open the page from inside the unpacked folder. Opening it inside a ZIP preview or copying out just the page can leave its supporting files behind.
  2. If you moved or renamed files, try opening a fresh copy of the complete site with its folders arranged as supplied.
  3. Reopen the starting page in your browser. If the controls are still missing, check whether the browser allows scripts, the small programs that make the controls work. If the settings are managed for you, ask the site’s author or your agent to help check the copy you received.
