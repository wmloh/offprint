Making pages with an agent

You decide how readers should use your page, and an agent builds it from your description. These guides give you the names of DocForm’s tools so you can choose the ones that fit.

Reading time
About 5 minutes
You will
Know how to ask for the features you want

Features have official names

An agent is an AI assistant that can create and edit pages for you. Each DocForm tool has an official name you and the agent can use to refer to the same thing.

For example, Tooltips show a quick explanation beside a word. Peek bubbles open a block of optional detail inside the page. Naming the tool makes it clear where and how the reader should see the explanation. Use the Feature directory to find a tool’s name.

On by default or on request

On by default
A standard DocForm page comes with Base layout, Text roles, Buttons, Tags, Callouts, Section lines, Colour roles, Theme, Navigation, Reading controls, Tooltips, Cross-references, Citations, Sidenotes, and Search. The agent still supplies the content they act on, such as which words need a tooltip.
On request
The agent turns on extra tools where you want them. Examples include Peek bubbles, TeX math, Code, Tabs, SVG charts, and Figure zoom.

The tags on the feature guides tell you which choice applies. Some tools work together. The agent can set up what a tool needs to work.

Describe the result

Start with who will read the page and what they should be able to do. Gather the words, pictures, or data they need. Decide what readers should see first, what they should be able to explore, and what they can skip.

Choose a DocForm tool when it helps a reader do one of those things. Give the agent its official name and describe the result you want to see. The agent writes the page and sets up the tools. Open the finished page in your browser and try it the way a reader would.

The agent follows shared conventions

DocForm ships with authoring conventions for agents: a recommended folder layout, when to reach for a built-in feature before writing custom code, how to keep pages working offline and ready to export, and a checklist to run before handing a site back. You do not need to read them, but you can ask the agent to follow them so every page in your site behaves the same way.
