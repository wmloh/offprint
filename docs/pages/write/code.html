Highlights and notes

Try it

Point at a circled number or reach it with Tab. Its annotation, a numbered note about the line, lights up below and appears in a small card. Choose the number to jump to its note. Use Copy to copy the text without the annotation markers.

The background of the second line is a line highlight. It stays in place so readers can spot the line before they interact with it.

Language colours

Try it

Choose Python, then JSON. Look at how quoted words and numbers pick up different colours. With a tab focused, use the left and right arrow keys to see more languages. These colours help separate parts of the program text, a feature called syntax highlighting.

Changes between versions

Try it

Find the line that stayed the same in each example. A diff is a view of what changed. Copying a diff includes kept and added lines, so you get the newer text.

Plain blocks

A language outside the nine built-in highlighters can still use the code toolbar and Copy. The plain-block option shown here leaves the toolbar off too.

When to reach for it

Use a code block when the exact text matters. Pick a few lines to highlight so readers can see where to begin. Use a diff when the change itself is the story.

For every reader

On narrow screens, wide blocks can scroll sideways. Write annotations in a numbered list so the explanations remain available in print and with scripts off. With scripts off, the original text stays visible and every language panel is shown.
