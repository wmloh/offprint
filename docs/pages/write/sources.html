Giving credit

Start with a title and a few landmarks the eye can find easily (Visual hierarchy: guiding the eye). Save the strongest colour accents for things that need immediate attention (The signal ladder).

Both guides cover ways to direct attention (Visual hierarchy: guiding the eye and The signal ladder).

Try it

Pause over a bracketed number or reach it with Tab to see the full source in a card. Choose the number to jump to the source list, then use its return arrow to go back to the first mention.

A citation credits a source. DocForm numbers sources in the order you first mention them, reuses the number on later mentions, and builds a bibliography, the list of cited sources.

When to reach for it

Use cross-references when readers may want to inspect a figure or equation again. Use citations when a claim comes from a source readers may want to look up.

For every reader

Give each figure and table a caption that makes sense in print and on a narrow screen. With scripts off, the source titles stay in the paragraphs and the bibliography still gives their names.
