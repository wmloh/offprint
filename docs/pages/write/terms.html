A quick definition

Try it

Point at “section marker” and then “visual hierarchy”, or reach each one with Tab. A tooltip is the small box that appears over the page. A shared glossary term uses the same explanation wherever it appears.

A longer explanation

Try it

Press and hold the first term, or hold Enter or Space with the term focused. The ring fills in about six tenths of a second, the default wait. The second term is set to take 1.2 seconds. Release early or move the pointer away to cancel, and press Esc to dismiss the open hold-to-expand card.

A site can set its own wait, and an individual term can override it. Hold works when the term has a longer explanation available.

Faint underlines

Try it

Point at the first “Contrast”, then try the same word on the second line. With auto-linking turned on, DocForm finds whole terms in paragraphs and list items, even when their capital letters differ. It skips headings, links and buttons, code, formulas, and text that already has a tooltip. A page can also exclude an entire passage.

The generated glossary

Open the Glossary to browse the site’s definitions. DocForm groups them by first letter. With the offline search index available, it can also collect tips written on individual pages, show different definitions of the same term, and link to the sections that use it.

When to reach for it

Use a short tooltip to unblock a sentence and a longer card for an example readers might want next. Put a definition used across several pages in the glossary so it stays consistent.

For every reader

Explicit tooltip terms can receive keyboard focus. Automatically underlined words keep the tab order short, so use the glossary page for keyboard lookup. Write essential definitions in the page text so they’re available in print and with scripts off.
