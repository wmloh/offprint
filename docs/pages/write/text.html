The reading column

Try it

Compare the demo’s width with the space available to this paragraph. Then make your browser window narrower and watch the labels move above their values as space runs out.

The reading column keeps lines short enough to follow. OffPrint also keeps figures, tables, and code within that column. You can cap one block at a narrower width. Pictures can shrink to fit, and wide tables and code blocks can scroll sideways.

Tags and buttons

OffPrint groups Tags and Callouts under the name Blocks. Both come with the reading profile.

Reading aids On by default

The same status tag works next to prose, in a heading, or inside a table.
FeatureAvailability
TeX mathOn request

Sidenotes are On by default. A tag names a status in a few words. Rest the pointer on a tag to see what it means. Every tag has a tooltip: give it its own short explanation, or let it borrow the description of its colour role. OffPrint warns when one is missing. A button gives the reader an action. Its tint can use the same colour roles as tags, and an icon can sit beside its label.

A shape on the left of each tag shows what kind of tag it is, so two tags of the same colour are never confused. On this site a triangle marks availability, as in On request, a square marks a colour sample, and a diamond marks a keyboard shortcut. The circle is kept for term types, such as Design, which sort the glossary. The site settings list each kind and its shape. A tag that belongs to no kind gets a dashed red outline and a warning, so it is easy to spot.

When to reach for it

Let headings and space do most of the work. Save tinted tags for statuses readers need to spot and prominent buttons for actions they’re likely to take.

For every reader

Headings, lists, tags, and ordinary buttons retain their styling with scripts off. The step example shows both steps. On phones and in print, row and column headings still make a table readable without its hover tint.
