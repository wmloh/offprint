The reading column

Try it

Compare the demo’s width with the space available to this paragraph. Then make your browser window narrower and watch the labels move above their values as space runs out.

The reading column keeps lines short enough to follow. DocForm also keeps figures, tables, and code within that column. You can cap one block at a narrower width. Pictures can shrink to fit, and wide tables and code blocks can scroll sideways.

Headings and labels

Section details

Compare this page’s title, the section heading above, and the smaller “Section details” heading. Each size tells you how much of the page the heading covers. In the demo, “At a glance” is an eyebrow, a short label that introduces a block. The aligned pairs underneath are labelled fields. Use them for a handful of named facts a reader can scan.

Tags and buttons

Reading aids On by default

The same status tag works next to prose, in a heading, or inside a table.
FeatureAvailability
TeX mathOn request

Sidenotes are On by default. A tag names a status in a few words. A button gives the reader an action. Its tint can use the same colour roles as tags, and an icon can sit beside its label.

When to reach for it

Let headings and space do most of the work. Save tinted tags for statuses readers need to spot and prominent buttons for actions they’re likely to take.

For every reader

Headings, lists, tags, and ordinary buttons retain their styling with scripts off. The step example shows both steps. On phones and in print, row and column headings still make a table readable without its hover tint.
