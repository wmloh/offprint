Inspect your own run output

This page compares your results with the vision-baselines sweep from the experiment results page. Drop a file from your own run into a box, or choose one. The browser reads it on this computer; nothing is uploaded. Try the files in the sample-output folder beside this page.

Browse the sweep configuration

The tree view opens nested data one level at a time. Click a row or use the arrow keys: Right opens a node, Left closes it, and Up and Down move between rows.

Compare your training curve

The chart shows the validation accuracy of the reference cnn-base run. Drop a history.csv with an epoch column and one column per curve to plot yours on the same axes. Curves named train and val keep their colours.

Drop a training history (CSV)
