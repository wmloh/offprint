Linear algebra, briefly

Linear algebra studies vectors, the matrices that act on them, and the linear map each matrix describes. It is the language behind computer graphics, data analysis, and quantum mechanics, and most of it can be drawn.

What you need

  • Comfort with algebra and the coordinate plane.
  • The idea of a function as a rule x \mapsto f(x).
  • No calculus. Everything here lives in \R^2.

A first picture Example

Every vector in the plane is a linear combination of two building blocks, \vec e_1 = (1, 0) and \vec e_2 = (0, 1). Here is (3, 2) = 3\vec e_1 + 2\vec e_2, built one piece at a time.

Vectors in code

In code, a vector is just an array. The tabs below share a group with the code on the matrices page, so choosing a language here also chooses it there. 

// Add two vectors component by component.
const add = (u, v) => u.map((x, i) => x + v[i]);
const scale = (k, v) => v.map((x) => k * x);

console.log(add(scale(3, [1, 0]), scale(2, [0, 1]))); // [3, 2]
import numpy as np

e1, e2 = np.array([1, 0]), np.array([0, 1])
print(3 * e1 + 2 * e2)  # [3 2]

Why "linear"?

Lines stay lines

The maps studied here send straight lines to straight lines and keep the origin fixed. Algebraically, they respect addition and scaling, which is the definition of a linear map.

Why start with the plane?

Every idea in these notes works in \R^n, but in \R^2 you can see it. Once a picture makes sense, the formulas follow it.
