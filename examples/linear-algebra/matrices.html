Matrices

Definition A matrix is a grid of numbers. A 2 \times 2 matrix has two columns, \vec a_1 and \vec a_2:
A = \begin{pmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{pmatrix} = \begin{pmatrix} \vec a_1 & \vec a_2 \end{pmatrix}.

A matrix times a vector

The product A\vec x is the linear combination of the columns of A with weights taken from \vec x:

A\vec x = x_1 \vec a_1 + x_2 \vec a_2.

Work through a matrix-vector product

Take A = \begin{pmatrix} 2 & -1 \\ 1 & 1 \end{pmatrix} and \vec x = (2, 1).

  1. Read the inputs. The columns of A are (2, 1) and (−1, 1). The entries of x give them weights 2 and 1.
  2. Scale the first column. Multiply both coordinates by 2 to get (4, 2). The second column keeps its original coordinates because its weight is 1.
  3. Add the second contribution. Start at (4, 2) and move by (−1, 1). The endpoint is (4 − 1, 2 + 1) = (3, 3).
  4. Read the product. The sum starts at the origin and ends at (3, 3), so Ax = (3, 3).

Multiplying matrices

The product AB applies B first, then A .Reading right to left matches function composition: (AB)\vec x = A(B\vec x). Its entry in row i and column j is the dot product of row i of A with column j of B:

(AB)_{ij} = \sum_k a_{ik} b_{kj}.

Order matters

Not commutative In general AB \ne BA. For example,
\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \qquad \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}.

Other familiar rules still hold:

  • Associativity: (AB)C = A(BC).
  • Distributivity on both sides:
    • A(B + C) = AB + AC,
    • (A + B)C = AC + BC.
  • The identity changes nothing: IA = AI = A.

Matrices in code

These tabs are synced with the ones on the introduction page.

// Multiply two matrices stored as arrays of rows.
function matmul(A, B) {
  return A.map((row) =>
    B[0].map((_, j) => row.reduce((sum, a, k) => sum + a * B[k][j], 0))
  );
}

const A = [[0, 1], [0, 0]];
const B = [[0, 0], [1, 0]];
console.log(matmul(A, B), matmul(B, A)); // not equal
import numpy as np

A = np.array([[0, 1], [0, 0]])
B = np.array([[0, 0], [1, 0]])
print(A @ B)  # [[1 0] [0 0]]
print(B @ A)  # [[0 0] [0 1]]
