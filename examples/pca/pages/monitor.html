How a window becomes an alert

Retain the first k directions in W_k. Reconstruct the standardized row z and sum the squared residuals.

\hat z=zW_k W_k^\top,\qquad Q_k=\norm{z-\hat z}^{2}=\sum_{j>k}a_j^2

Because the four directions form an orthonormal basis, the right side of gives the same score directly from the discarded components.

The reconstruction captures variation similar to the baseline. A large residual means the sensor combination departed from those learned directions.

For this exercise, every rank uses the same threshold. Flag a window when Q_k > 0.80 in squared standardized units.

How could an operator catch the common-mode offset?

Watch retained scores as well as residuals. One option is a score-space statistic such as T^2=\sum_{j=1}^k a_j^2/\lambda_j. Implement the residual rule

Use the same post-fit score convention in both languages. The change below replaces a rule that monitors all score energy with one that isolates energy outside the retained subspace.

def residual_score(scores, rank):
    return sum(score**2 for score in scores)
def residual_score(scores, rank):
    return sum(score**2 for score in scores[rank:])
