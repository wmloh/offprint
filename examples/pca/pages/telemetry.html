Follow the incident on two clocks

The sensor timestamps each window at acquisition. The gateway records receipt in seconds since its 12:59:30 UTC startup. Use Previous and Next to follow the events, or select a keyed point in the chart.

  1. Record a normal window. Rank two leaves a residual of 0.21. The gateway records the reading one second after acquisition.
  2. Notice the drift before the alert. The rank-two residual is 0.28 and stays below the alert threshold.
  3. Flag the low-pressure window. After the gap, the rank-two residual reaches 1.45. The gateway receives this window three seconds late.
  4. Observe recovery. The rank-two residual returns to 0.31. The gateway receives the window after one second.

Count each window once

If the gateway resends the 08:45 window, count its alert once. Keep the first arrival per window ID within a replay of this pump's telemetry. Both snippets count distinct flagged windows.

WITH ranked AS (
  SELECT q2, ROW_NUMBER() OVER (
    PARTITION BY window_id ORDER BY received_at, arrival_id  -- (1)
  ) AS arrival_rank
  FROM pump_arrivals
)
SELECT COUNT(*) AS alerts
FROM ranked
WHERE arrival_rank = 1 AND q2 > 0.80;
