A decoder-only Transformer, step by step

Start with the train is. Follow three token IDs through an attention head and a feed-forward layer, then turn the last position's state into a distribution over the next token.

The worked model Six vocabulary entries, two coordinates per token, one causal attention head, and one feed-forward layer. The parameters are chosen by hand so that the entire forward pass can be checked.

Trace a token to its attention weights and output.

Split the prompt into token IDs

Our miniature tokenizer lowercases the text, treats the period as its own token, and looks up each piece in a six-entry vocabulary.The vocabulary order fixes both the input row lookup and the order of the output logits.

The IDs in name vocabulary rows. The difference between IDs 0 and 1 has no geometric meaning.

A real tokenizer may emit pieces smaller than a word. Always use the tokenizer paired with the model's embedding and output tables.

Run the lookup

import re

vocab = ["the", "train", "is", "late", "here", "."]
lookup = {token: i for i, token in enumerate(vocab)}
pieces = re.findall(r"\w+|[^\w\s]", "the train is".lower())  # (1)
ids = [lookup[piece] for piece in pieces]  # (2)
  1. Group word characters and keep each punctuation mark as a separate piece.
  2. Look up each piece. A piece outside the six entries raises a lookup error in this example.
const vocab = ["the", "train", "is", "late", "here", "."];
const lookup = new Map(vocab.map((token, i) => [token, i]));
const pieces = "the train is".toLowerCase().match(/\w+|[^\w\s]/g) || [];
const ids = pieces.map(piece => {
  if (!lookup.has(piece)) throw new Error("Unknown token: " + piece);
  return lookup.get(piece);
});

Give each token a position

Use the rows of for token identity and add one vector per sequence position. In the example, the position vectors are (0,0),\ (0,0.5),\ (0.5,0). The attention layer receives:

Why add position information?

The same embedding is reused whenever a token appears. Position information lets a layer distinguish where each instance occurs. This example adds position vectors before the first layer, as in the original Transformer design.

Check the third row

The embedding for is is (1,1). Adding the third position vector gives (1.5,1).
