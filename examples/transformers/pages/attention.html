Causal self-attention

Each position uses its query to select information from earlier positions and itself. Inspect one attention head with a vocabulary and prompt from the input chapter.

Score, mask, normalize

Queries and keys determine the weights. Values carry the information combined with those weights. This head uses identity projections, so Q=K=V=X. The causal mask sets the upper triangle to negative infinity before softmax.

A=\softmax_{\mathrm{row}}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right),\qquad Y=AV,\qquad M_{ij}=\begin{cases}0& j\le i\\-\infty&j>i\end{cases}

Attention steps

Scaled dot products

Take each query–key dot product and divide by \sqrt{2}, since a key has two coordinates.

Block keys beyond the query

The first query can use one key. The second can use two. The third can use all three. The upper triangle is excluded.

Normalize each row

Softmax turns allowed scores into weights that sum to one per row. Use each row to mix the value vectors. The drawn weights are rounded.

Trace a token through attention

Each prompt position supplies one query row. At temperature 1, the weights for that row mix the value vectors for the (1, 0), train (0, 1.5), and is (1.5, 1). The output is the resulting weighted sum. Future keys are masked and contribute zero.

Change the query position

Compare the weights for all three queries. Where can the head assign weight when the query is at position 1? What changes when a query can see a longer prefix?

At query position 3, 0 of 3 keys are masked. Temperature divides the remaining scores before softmax. The worked forward pass uses 1.

Weighted value vector: (1.133, 0.908).

Why does the third query weight “the” and “train” equally?

Its dot products with (1,0) and (0,1.5) both equal 1.5. The same scale and softmax denominator apply to both. Their value vectors still differ.

Why mask before softmax?

Masking before normalization gives the entire probability mass to allowed keys. If you first normalized across all keys and then zeroed future positions, the surviving weights could sum to less than one.
