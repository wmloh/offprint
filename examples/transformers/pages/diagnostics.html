Package results for offline viewing

To swap the built-in run log, keep its column names and wrap the edited CSV with the offline data file converter. Load the resulting script before DocForm core. The shell command checks the first few lines, and the HTML and CSS show the markup for a wide data view and a limit on its width.

head -n 5 runs.csv
<div class="run-log" data-df-data="runs" data-df-wide></div>
