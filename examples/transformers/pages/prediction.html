Stabilize softmax

Subtract the largest logit before exponentiation. Each numerator and the denominator gain the same factor, so the probabilities stay the same. The largest exponential becomes 1, avoiding overflow.

from math import exp

def probabilities(logits, temperature=1):
    weights = [exp(x / temperature) for x in logits]
    total = sum(weights)
    return [w / total for w in weights]

def probabilities(logits, temperature=1):
    peak = max(logits)
    weights = [exp((x - peak) / temperature) for x in logits]

Sweep the learning rate

Before training on a larger corpus, run the same short training job at several learning rates and compare the final cross-entropy losses. Learning rates are usually tried in steps of about 3×, so a log scale places each step the same distance apart. Losses also span two orders of magnitude here, so both axes use log scales. The numbers are illustrative.
